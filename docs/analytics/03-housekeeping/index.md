title: Housekeeping
---

Maintaining a summary table involves ensuring that the data in the summary table
is up-to-date with the source table. The framework detects the changes to the
source data, and refreshes the affected parts of the summary table in the
background.

All the console commands are listed in [Console
Commands](../14-console-commands.md).
